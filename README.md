## Description
This C program implements basic matrix operations using functions and 2D arrays for better modularity.

It performs:
1. Matrix Addition
2. Matrix Multiplication  
3. Transpose

## Features Implemented as per Task
- ✅ Use of 2D arrays - `int mat[MAX][MAX]`
- ✅ Use of Functions for modularity
    - `inputMatrix()` - to read matrix
    - `printMatrix()` - to display matrix
    - `addMatrix()` - for addition
    - `multiplyMatrix()` - for multiplication
    - `transposeMatrix()` - for transpose
- ✅ Menu Driven with `switch(choice)`
